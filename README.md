# Club de Robótica UNAE

Prototipos y ejercicios del club de robótica.

## Proyectos

- [Explorador WiFi](proyectos/explorador-wifi/README.md): control web para ESP8266 y control de dos servos mediante Arduino.
- [Controlador del mando](proyectos/controlador-del-mando/index.html): interfaz final con teclado, pantalla táctil, mando y velocidad; su HTML coincide con el que sirve el ESP8266.

Los proyectos son prototipos académicos. Revisa el código y las conexiones de cada placa antes de cargar el firmware.
